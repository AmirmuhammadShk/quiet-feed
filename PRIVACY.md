# Privacy Policy for Quiet Feed

Quiet Feed processes visible page text locally to decide which posts to hide. It does not collect, transmit, sell, or share personal information, browsing history, page content, or usage analytics.

When blocked-content history is enabled, the extension stores blocked text, site, policy, link, and time in Firefox's local extension storage. It retains the 2,000 most recent entries by default. Users can search, export, clear, or disable this history from settings. Policies, keywords, site configuration, preferences, and a total blocked counter are also stored locally.

The broad website access permission is required so user-created site configurations can work without a new extension release. Page content is used only in memory for local keyword matching.

Privacy questions can be submitted through the repository's GitHub issue tracker. Do not include private browsing or account data in public issues.
