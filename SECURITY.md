# Security Policy

## Supported version

Security fixes are applied to the latest released version of Quiet Feed.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose browsing data, stored blocked content, or extension privileges. Use the repository's **Security → Report a vulnerability** workflow. Repository maintainers should enable GitHub private vulnerability reporting under **Settings → Security → Code security and analysis**.

Include a description, reproduction steps, affected version, impact, and any suggested mitigation. Do not include real private browsing or account data in a report.
