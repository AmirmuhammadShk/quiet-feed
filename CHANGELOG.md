# Changelog

All notable changes to Quiet Feed are documented here.

## 1.0.0 - 2026-08-05

First public release.

- Added configurable keyword policies with any/all matching.
- Added the default English and Persian AI/LLM policy.
- Added X/Twitter timeline filtering.
- Added viewport-based LinkedIn post-body filtering.
- Added configurable custom sites and CSS selectors.
- Added local blocked history, search, site filters, JSON/CSV export, and counters.
- Added light and dark interface themes.
- Added local-only privacy controls and Firefox data-collection disclosure.
